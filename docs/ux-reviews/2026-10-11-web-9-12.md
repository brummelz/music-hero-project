# Child UX review: ages 9-12 (web version)
Reviewed: Horn Hero web build on branch html-version, via 33 screenshots (desktop, tablet, phone; steps 1-11; ?sim keyboard simulator), plus web/index.html, web/css/app.css, web/js/ui/*.js, web/js/app.js, web/js/core/feedback.js, spec FR-03/07/16/18/21-25, NFR-01, section 6.1, and the earlier desktop review docs/ux-reviews/2026-10-10-9-12.md. Date: 2026-10-11.
Evidence limits: static screenshots only; the app was not launched. No real microphone or horn (keyboard simulation), so pitch lag, dropouts and the 150 ms grace were not experienced. Sounds (reference tone, success chime) not heard. The browser microphone-permission prompt and the denied-permission help panel were not captured (code read only). Not captured in any screenshot: the "Hold to open settings" toast, the hold-ring fill on the gear, the "So close! Start the hold again." message, the practice-complete screen, a 1- or 2-star level summary, phone landscape, real touch behaviour. Tablet game screens predate the staff-size fix (unverified after the fix). Pixel sizes below are inferred from screenshots assuming the phone shots are 2x density (390 css px wide); unverified.

## Age 9-12
**Verdict:** A 9-12 child gets going fast, reads the gauge easily and trusts the feedback, and the web layout holds up on phone and tablet. But the one-and-only first tap (the cover's Start Game) is small on a phone and also triggers a one-shot browser permission prompt, and the reward moments are still thin for a child who wants something to beat.

**What changed since the desktop review (status of earlier findings)**
- Fixed: opposite-arrow clash. Gauge chips are now "♭ Flat / ✓ In tune / ♯ Sharp" with no vertical arrows; only the message bar has one arrow (up when flat, down when sharp) (desktop-4, desktop-5, phone-4, phone-5).
- Fixed (code, not seen live): stars are explained. Level summary says "Amazing! All 3 stars (0 restarts)." and for fewer stars "You had N restarts. Keep it to X or fewer to win all 3 stars." (X comes from the configured constant). Only the 3-star text was seen (desktop-9).
- Fixed (code, not seen live): lost hold of 1 s or more shows "So close! Start the hold again." for 1.5 s (feedback.js TRY_AGAIN; game.js).
- Fixed (code): opening settings pauses the game and resumes on close; the gear needs a 1-second hold.
- Fixed: message flicker (0.4 s minimum message time).
- Remains: practice-complete reward is a sentence plus a points row, no personal-best (code: screens.js showPractice).
- Remains: settings tolerance still shows a preset dropdown plus an unlabeled "15" box, and "cents" is unexplained (desktop-11, phone-11).
- Remains: small grey captions ("Written pitch · Horn in F", "Hold for 3 seconds") and "Written pitch" jargon (desktop-3 to 7; 0.8rem on phone).
- Remains: far flat/sharp message bar turns pink-red (desktop-4, desktop-5, phone-4, phone-5).
- Remains: completed level rows on home have stars but no "Replay" cue (desktop-10, phone-10).
- Unchanged: the cartoon cover (child, mascot microphone, bunnies) still reads young for the top of this band.

**What works**
- Home (desktop-2, phone-2): one question, two big cards, big Do / Ré / Mi tiles with a check badge on the chosen one (not color alone), a Play pill on the current level and dashed "Locked" rows. The star total "3 / 15" is a clear target (phone-10).
- Practice screens: staff first, gauge below, message bar last. Flat / In tune / Sharp is shown by needle position, a highlighted chip with a symbol and text, and message wording, never color alone. The needle is a dark bar with a white border, readable on every zone.
- "Hearing DO / C4" next to the message (desktop-4, phone-4) gives this age exactly the "what does it think I played" detail they want, and it reads as fair.
- Silence (desktop-3, phone-3) is a calm invitation: pale zones, dashed needle, dotted ring, "Take a breath and play your Do!", "Listening...". Not an error.
- Hold progress: green ring fills around the notehead, notehead turns green, "2.0 / 3.0 s" (desktop-6, phone-6). Exact and fair-looking.
- Positive wording throughout (FR-16, FR-18): "A bit low! Lift the note up.", "A bit high! Relax and come down.", no failure words.
- Touch targets in the game are 48-52 px (back, speaker, gear, pills, buttons); note tiles and the Start practice button are much larger. Phone layout stacks cleanly: back and gear and score on one row, target note below, nothing overlapping (phone-3 to 7).
- Summary (desktop-9, phone-9): "Level 1 complete!", three big stars, a reason line, "Level 2 unlocked" chip, and the next step as the filled button.
- Settings (desktop-11, phone-11): "For grown-ups", saves at once, live mic test, plain preset names. The phone dialog is full-width and readable.
- Tab-away pauses the game so a hidden page never costs a restart (app.js).
- Reduced-motion is respected in CSS; no flashing seen.

**Problems**
1. [Major] Cover on phone (phone-1) - "I want to start, but the Start Game button is tiny and the picture is stuck in the middle of a mostly empty screen." On a portrait phone the cover art fills about a third of the screen and the button, being part of that scaled image, is roughly 140 x 28 css px (inferred), below the 44-48 px used everywhere else. It is the only action on the screen. Likely behavior: missed taps, a second tap during "Warming up the horn...", or the child stops. Tablet (tablet-1) is better (about 60 px tall) but still small relative to the screen. -> Fix: in narrow portrait, keep the illustration but render Start Game as a normal full-width button below it (min-height about 56 px, same style as .primary), or scale the cover to fill the height. Keep it one obvious action.
2. [Major] Cover, microphone permission (spec 6.1; prompt not captured, unverified) - "A box popped up asking to use the microphone. I tapped Block (or ignored it), now nothing works." The child sees a system dialog they did not expect, in the middle of "Warming up the horn...". Chrome and Safari remember a Block, so "Try again" on the help panel (mic-help) will not bring the prompt back; the panel tells the child to find "the lock icon next to the address", which is an adult-level step and does not exist in some phone or installed-app views. Likely behavior: the child feels they broke it; a grown-up must step in. The help wording is positive (no failure state, FR-16 respected). -> Fix: before the tap, add one short line under or beside Start Game: "Next, tap Allow so Horn Hero can hear your horn." Make the help panel say which two taps to make for the common browsers, and offer a "Ask a grown-up" line. Do not remove the permission request from Start Game (spec 6.1).
3. [Major] Practice complete (code only, screens.js showPractice; carried over from the desktop review) - "I did 10 and just got a sentence." The reward is "You did it!", a row of 10 points and "You held 10 steady Do notes. Super playing!". Nothing to beat tomorrow. This age is motivated by mastery. -> Fix: add one line from the local profile (FR-25) such as "Fewest restarts so far: 3" or "Best run without restarting: 6"; keep it star-free (FR-24). Not screenshotted, so verify the layout.
4. [Minor] Point scored (desktop-7, phone-7) - "It says Great job, but the timer already says 0.5 / 3.0 s and the ring is filling again." In practice mode the same note repeats, so the green ring and the hold timer start again under the celebration message. A 9-12 child reads this as a glitch or "do I keep holding?". The reward itself is small: one dot turns into a star in the score pill and a chime. On phone the dot row is hidden, so only "1 / 10" changes (phone-7). -> Fix: hide the hold time text during the 1.2 s celebration, and add a larger pulse on the score pill or a "+1" popup that works on phone too. Do not change the hold rules (FR-07).
5. [Minor] Settings gear, hold-to-open on touch (not seen live) - "I tapped the gear and a small message said Hold to open settings, so I held it." The hold (1 s, ring fills) stops accidental taps from toddlers but not a curious 9-12 child, because the toast tells them how. It also sits beside the score pill on phone (phone-3), same size as Back. That is acceptable for this age (settings are saved immediately and do not break anything, but tolerance changes mid-level change star outcomes, FR-21/FR-22). -> Fix: no change needed now; optionally make the toast say "Grown-ups: hold to open settings" and consider a longer hold only if testing shows children changing tolerance. Check that the 1 s hold survives a finger sliding slightly (pointerleave cancels it, which may be too strict on a phone).
6. [Minor] Settings (desktop-11, phone-11) - "What is 'cents'? What is the box with 15?" The unlabeled number box sits next to the preset and is disabled unless "Custom" is chosen, so it looks broken. The phone dialog needs scrolling to reach Done and Reset progress; the microphone name is cut off ("no microphon"). -> Fix: label the box "Custom (cents)", add one sentence ("Easy forgives more"), and keep Done visible (sticky footer) on phone.
7. [Minor] Gauge labels and captions on phone (phone-3 to 7) - "I can hardly read Flat and Sharp." Chips drop to 0.9 rem and the captions to 0.8 rem while the staff card has a lot of empty white space (about 680 px tall for a 300 px staff). -> Fix: give the freed height to the gauge (taller bar, 1.1 rem chips) and captions at 1 rem; swap "Written pitch" for "Note on your music".
8. [Minor] Message bar (all game shots) - far flat/sharp turns the whole bar pink-red. Not failure wording, but alarm-like for a child who is only a little off. FR-03 colors the gauge only. -> Fix: keep red on the gauge, use the yellow bar for both near and far (UI choice, no spec change).
9. [Minor] Home (desktop-10, phone-10) - a completed level has stars but no hint it can be replayed; on phone the Adventure card starts below the fold (Leaps is cut off), so "what is next" needs a scroll. -> Fix: add "Replay" to completed rows; on phone consider putting Adventure above Practice, or keep the current level visible.
10. [Minor] Cover (desktop-1, tablet-1, phone-1) - cartoon child, mascot microphone and bunnies. Acceptable for 9-10, likely "babyish" for 11-12. Home and game are age-neutral. -> Fix: keep as the only young screen (same conclusion as the desktop review).
11. [Minor] Accessibility (desktop-11, phone-11) - the keyboard focus outline is yellow (#FFC93C) on light blue or white, low contrast (about 1.5:1 estimated, not measured). Idle gauge zones drop to 35% opacity (intended). Screen-reader reading of staff and gauge not tested. -> Fix: use the dark accent for the outline, or a double ring (white plus ink).
12. [Minor] Back button (code, app.js) - leaves a level at once with no confirmation, so progress in a half-finished level is lost. For this age, probably acceptable and consistent with the desktop app; check on phone, where it sits at the screen edge. -> Fix: optional, none needed if levels are only 6 prompts.
13. [Minor, unverified] Tablet portrait game screens (tablet-3 to 8) were captured before the staff-size fix: the staff was small inside a very tall white card. Re-check after the fix.
14. [Minor, unverified] Simulation pad ("Simulation: Flat / In tune / Sharp, or hold Space...") appears in all game screenshots because of ?sim; code hides it otherwise. Confirm it never shows in a real session.

**Would this child come back tomorrow?** Maybe. The loop is quick and feels fair, and the "Hearing DO / C4" readout and the stars explanation give a 9-12 child something to master. What is missing is a visible personal best and a bigger "I did it" moment; and on a phone, the first tap and the permission prompt are the biggest risks that the child never gets that far without a grown-up.

## Cross-age summary
Only age 9-12 was reviewed here.
- Ranked issues likely shared with other bands: (1) phone cover Start button size and the permission prompt (hits every band, hardest for 3-8, who cannot read the help text); (2) thin reward on practice complete and point scored; (3) small phone captions and chips; (4) pink-red message bar; (5) settings jargon ("cents").
- Likely conflicts: the cartoon cover suits younger children and may feel young to 12-15. The "Hearing DO / C4" detail and the restart count suit 9-15 but add reading for 6-8. Resolution: keep these as small secondary text and let the large icon, chip and message carry the meaning.
- Spec flags (do not change silently): (a) Spec 6.1 requires Start Game to also request the microphone; the fixes above only add explanation, they do not move the request. (b) FR-22/FR-23 miss-based stars: the summary now exposes restarts, which agrees with the spec; the threshold (assumption, open question 1) is shown to the child, so changing it later changes visible text. (c) FR-07 hold reset and the 150 ms grace interact with FR-22 miss counting (the "So close!" cue only shows when a hold of 1 s or more is lost); real-horn behaviour is unverified. (d) FR-24 no stars in practice: respected, so the practice-complete reward must come from non-star progress. (e) FR-03 colors the gauge zones only, not the message bar.
