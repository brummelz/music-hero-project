# Child UX review: ages 12-15
Reviewed: Home screen Practice card (7-note 4+3 grid) from code: ui/home_screen.py (_build_practice_card), ui/theme.py (QPushButton#note), web/css/app.css (.note-choices, .note-choice, phone block ~l.404), web/js/ui/screens.js; spec lines FR-16, FR-18, FR-24, Screen 1. 2026-10-23
Evidence limits: App not run, no screenshots. Layout, wrapping and contrast are inferred from code. docs/design mockups were not re-checked for the 7-note grid (unverified). The 600px phone block was only partly read.

## Age 12-15
**Verdict:** Reads as a competent, no-nonsense picker. Seven notes at once feels like a real instrument tool, not a toy, but it needs a clear selected state and an orderly layout.
**What works**
- Seven named notes (Do..Si) with the letter below (C..B) give the "actual information" teens want. Both naming systems are shown, so there is no guessing.
- Selected state in the web build pairs color with a check mark (.note-choice[aria-checked="true"]::after), so it is not color alone.
- Large targets (100px min in Qt, 84-120px on web). No misclick risk.
- Copy is short and neutral ("Pick one note and play it 10 times.", "Hold the note steady for 3 seconds to score a point."). Nothing patronising and no failure wording (FR-16, FR-18).
- Default note is preselected, so "Start practice" works in one click.
**Problems**
1. [Major] Home / Practice card, Qt build - "Which one did I pick?" The checked state in theme.py is only a tinted background and an accent border. There is no check mark, unlike the web build. Seven similar tiles make this harder to read, and colour-blind users may miss it. -> Fix: add the same check badge (or a bold ring plus icon) to QPushButton#note:checked. This matches the web behaviour.
2. [Major] Practice card, 4+3 grid - "Why is the last row short and left-aligned?" Seven notes in four columns leaves an empty fourth cell in row 2. It looks unfinished, and Si sits alone at the end of the scale. -> Fix: leave the grid as is, but make the last row start at the left with the empty cell clearly empty, or use a tidy 4+3 layout with the three centred. Do not stretch the last row, because that would make the tiles unequal.
3. [Minor] Qt tiles - Solfege is 42px and letter 20px inside a 100px-tall button. With 4px borders and 0 spacing this is tight but should fit. -> Fix: check on a real display at the smallest window size. Unverified.
4. [Minor] Phone block (web) - At about 360px wide, four columns with 12px gaps give tiles of about 70px width. "Sol" at 2.1rem should still fit, but it is close. The check badge (22px) can crowd the label. -> Fix: verify on a 360px device. If it wraps, drop to 3 columns under about 400px (3+3+1), or shrink the badge. Unverified.
5. [Minor] Practice card - The "10 times" in the header and "score a point" in the hint use different words for the same goal. A teen will notice the mismatch. FR-24 says 10 points. -> Fix: use one phrase, e.g. "Hold it steady for 3 seconds. Get 10 points."
6. [Minor] Practice card - Written pitch C4-B4 is shown only as a letter with no octave. A teen horn player may wonder whether it is written or sounding pitch. -> Fix: add a small tooltip or help line ("written pitch"). This is not required by the spec.
7. [Minor] Keyboard - The Qt buttons are checkable and focusable. The web tiles use role="radio" but arrow-key navigation is unverified. -> Fix: confirm arrow keys move the selection in a radio group on web.
**Would this child come back tomorrow?** Maybe-yes. The seven-note choice gives more control and a wider range, which a teen respects. The selection feedback and layout polish are what decide whether it looks professional or childish.

## Cross-age summary
- Only 12-15 was reviewed, so no cross-age conflicts were assessed.
- One possible conflict for other bands: seven tiles in 4 columns makes each tile smaller than the old 3-in-a-row layout. Younger bands (3-5, 6-8) may need larger targets. Tile size (about 84px minimum) is still large, but this should be reviewed for 3-5.
- Spec check: FR-24 and the Screen 1 text list all seven notes, so the change matches the spec. Practice "10 times" is not defined in the FR text I read; confirm the wording against FR-24 (10-point goal). No behaviour change is proposed.
